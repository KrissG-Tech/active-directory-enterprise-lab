# active-directory-enterprise-lab

Enterprise Active Directory home lab built with Windows Server 2025 for Windows clients, covering AD DS, promotion to DC, DNS and network configuration, documenting the configuration and administration of a small enterprise Windows environment.

## Completed

- Windows Server 2025 installed
- Static IP configured
- Active Directory Domain Services (AD DS) installed
- Server promoted to Domain Controller
- DNS configured

## Planned

- Create OUs, users and security groups
- Join Windows 10 client to the domain
- Configure DHCP
- Configure Group Policy
- Join Xubuntu client to the domain
- Document troubleshooting and lessons learned
